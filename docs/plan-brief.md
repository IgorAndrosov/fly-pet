# Бриф: десктопный питомец «живая муха» (этап 1 — план)

## Что это
Игрушечный, но настоящий проект: питомец-муха, который живёт на рабочем столе Windows 11
как тамагочи и умеет осмысленно действовать.

## Цель
1. Живёт на рабочем столе: прозрачное окно поверх всех окон, спрайт PNG, анимации ходьбы и сна,
   короткие всплывающие реплики (речевые «облачка»).
2. «Мозг» на LLM: сам решает, чем заняться, и комментирует происходящее (через API, не локальная модель).
3. Реально что-то делает на компьютере — ограниченный белый список безопасных действий.
4. Петля потребностей (голод / энергия / настроение / внимание), которые гаснут со временем
   и влияют на поведение — это и есть тамагочи-механика.

## Стек и размещение
- Проект: `D:\Projects\fly-pet` (репозиторий уже создан, пустой, git init выполнен).
- Python 3.13 + PyQt6. Никакого Electron.
- Состояние питомца — JSON в профиле пользователя (не в репозитории).
- «Верхний мозг» — LLM через API DeepSeek, ключ берётся из переменной окружения
  `DEEPSEEK_API_KEY` (лежит в `C:\Users\igora\AppData\Local\hermes\.env`, оттуда грузится при запуске).
  Ключ в репозиторий не копировать, в код и логи не вписывать, в git не коммитить.
- Локальные модели не поднимать: 16 ГБ ОЗУ и почти полностью занятый commit-лимит.
- Секретов в коде и логах быть не должно.

## Безопасность действий (жёсткое требование)
- Действия питомца — только по белому списку из конфига.
- Каждое действие логируется.
- Все операции обратимы: «уборка мусора» = перенос файлов в отдельную папку-карантин, НЕ удаление.
- По умолчанию включён dry-run («только докладывать»), реальные действия — отдельным флагом.
- У питомца не должно быть возможности удалять файлы или менять настройки системы.

## Желаемый состав MVP (этап 1, 3–5 безопасных действий)
Примеры, не догма: сводка открытых задач; уборка отведённой «мусорной» папки (переносом);
напоминание; реакция на долгое бездействие пользователя; «сон» при простое.

## Этап 2 (по желанию, если этап 1 принят)
«Честная» локомоция: движением управляет спайковая connectome-модель
(аналог abgnydn/webgpu-fly: реальные веса FlyWire, LIF-нейроны, на выходе «скорость ходьбы +
смещение поворота»), спрайт ходит по этим выходам. В план этапа 1 включать только как задел
(точки расширения), не реализовывать.

## Ограничения проекта
- Ничего глобально не устанавливать и не прописывать в автозапуск.
- Не трогать другие проекты в `D:\Projects`, служебный `D:\hermes` и системные настройки.
- Весь интерфейс, реплики и сообщения — по-русски.
- Машина слабая по памяти: запуск питомца не должен требовать больше ~200–300 МБ ОЗУ.
