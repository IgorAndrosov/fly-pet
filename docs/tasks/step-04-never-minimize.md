# Правка: окно питомца не должно сворачиваться и не должно попадать в панель задач

## Замер (проверено владельцем на живом окне)
Окно 96×96 на позиции (620,420): `style=0x96000000` (флаг `WS_MINIMIZEBOX` отсутствует),
`exstyle=0x80000` (`WS_EX_TOOLWINDOW` отсутствует, `WS_EX_APPWINDOW` отсутствует).
После `SendMessageW(hwnd, WM_SYSCOMMAND, SC_MINIMIZE, 0)` окно получает
`isMinimized = True`, `windowState = WindowMinimized`.

Следствие: при «Свернуть все» / `Win+D` муха исчезает вместе с остальными окнами и перестаёт быть
видна на рабочем столе. Нужно, чтобы она оставалась.

## Что сделать
1. Конфиг `config/default.yaml`, секция `window` — два новых ключа с русскими комментариями:
   - `never_minimize: true` — окно немедленно возвращается из свёрнутого состояния;
   - `tool_window: true` — окно-инструмент (`Qt.Tool` / `WS_EX_TOOLWINDOW`): не попадает в панель
     задач и в список Alt+Tab, и оболочка Windows не сворачивает его командой «Свернуть все».

2. `fly_pet/window.py`:
   - при `config.window.tool_window` добавить `Qt.WindowType.Tool` в набор флагов окна (флаг
     `FramelessWindowHint` и `WindowStaysOnTopHint` по конфигу сохранить как есть);
   - при `config.window.never_minimize` перехватывать `changeEvent(QEvent.Type.WindowStateChange)`:
     если окно ушло в `WindowMinimized` — вернуть его в `WindowNoState` (`show()`), сохранив позицию и
     не забирая фокус (`WA_ShowWithoutActivating` уже стоит). Восстановление делать отложенно через
     `QTimer.singleShot(0, ...)`, чтобы не рекурсировать внутри обработчика состояния;
   - писать в лог `debug`-строку при возврате из свёрнутого состояния (для диагностики);
   - окно по-прежнему НЕ должно быть поверх всех окон (никакого `WindowStaysOnTopHint`, если в
     конфиге `always_on_top: false`) и не должно подниматься над другими окнами при восстановлении
     (не вызывать `raise_()`), достаточно вернуть видимость и позицию.

3. Тесты (`QT_QPA_PLATFORM=offscreen`), `tests/test_window_headless.py`:
   - при `never_minimize: true` после `win.setWindowState(Qt.WindowState.WindowMinimized)` и прокрутки
     событий окно не свёрнуто (`isMinimized() is False`) и видимо;
   - при `never_minimize: false` окно остаётся свёрнутым (то есть флаг реально управляет поведением);
   - позиция окна после восстановления не изменилась;
   - с `tool_window: true` в флагах окна присутствует `Qt.WindowType.Tool`.

4. `README.md` — короткий раздел «Поведение на рабочем столе»: муха не сворачивается вместе со всеми
   окнами, не отображается в панели задач и Alt+Tab, не является «поверх всех окон»; при этом она
   может быть перекрыта обычными окнами и уведомлениями.

## Чего делать нельзя
- Не делать окно always-on-top и не бороться с перекрытием обычными окнами — это осознанное решение
  владельца.
- Не реализовывать меню, реплики, потребности, еду — следующие шаги.
- Не менять спрайты, `tools/make_sprites.py`, `docs/plan-stage1.md`, `docs/decisions.md`.
- Не коммитить. Ничего не устанавливать.
