# Задача 3 (шаг 4 плана): прозрачное окно и анимации спрайтов

Работай только внутри `D:\Projects\fly-pet`. Ничего не устанавливай: PyQt6 6.11, Pillow, PyYAML,
httpx, pytest уже стоят в `.venv`. Другие проекты и `D:\hermes` не трогай. Комментарии, докстринги и
все пользовательские тексты — по-русски, UTF-8 без BOM.

Обязательный контекст: `docs/decisions.md` (согласованные решения) и `docs/plan-stage1.md`.
Спрайты уже лежат в репозитории: `assets/fly/idle_1.png`, `idle_2.png`, `walk_1..walk_6.png`,
`sleep_1..sleep_3.png`, `chew_1.png`, `chew_2.png` — все 64×64 PNG с альфа-каналом. Регенератор —
`tools/make_sprites.py` (не менять).

## 1. `fly_pet/animation.py`

- `load_frames(repo_root: Path) -> dict[str, list[QPixmap]]` — читает спрайты из `assets/fly`,
  группирует по состояниям `idle`, `walk`, `sleep`, `chew` в порядке номеров в имени. Отсутствие
  файла — понятное исключение по-русски, а не тихий `None`.
- `AnimationPlayer` — знает текущее состояние и играет кадры с частотой `tick.animation_fps` из
  конфига; метод `advance() -> QPixmap` (следующий кадр для текущего состояния, циклично) и
  `set_state(name: str)` (смена набора; при смене начинать с первого кадра). Состояния валидируются.
- Логика не должна зависеть от окна: плеер можно тестировать без показа окна.

## 2. `fly_pet/window.py`

- `FlyWindow(QWidget)`:
  - frameless (`Qt.FramelessWindowHint`), прозрачный фон (`WA_TranslucentBackground`),
    не крадёт фокус (`WA_ShowWithoutActivating`), окно **не** поверх всех окон, если в конфиге
    `window.always_on_top: false` (флаг выставлять по конфигу, а не жёстко);
  - размер — из `window.width`/`window.height`; кадр спрайта рисуется по центру окна в `paintEvent`;
  - стартовая позиция: `state.pose` (если задана и попадает в рабочую область), иначе правый нижний
    угол `availableGeometry` соответствующего экрана с отступом 24 px;
  - перетаскивание левой кнопкой мыши (`mousePressEvent`/`mouseMoveEvent`/`mouseReleaseEvent`),
    при отпускании — сохранить новую позицию в состояние через `StateStore`;
  - `set_click_through(enabled: bool)` — включение/выключение «клика сквозь» через Win32:
    `GetWindowLongPtrW`/`SetWindowLongPtrW` с `GWL_EXSTYLE`, флаги `WS_EX_LAYERED | WS_EX_TRANSPARENT`
    (добавлять и снимать, не ломая остальные биты); по умолчанию — значение
    `window.click_through` из конфига. На не-Windows платформе — no-op с предупреждением в лог.
  - таймер анимации на частоте `tick.animation_fps`; отдельный публичный метод `set_state(name)`
    для будущих действий.
  - при закрытии окна и при выходе приложения состояние сохраняется (`aboutToQuit`).
- Питание точки кормления и еда в этом шаге НЕ реализуются (только позиция окна).

## 3. `fly_pet/app.py`

- `build_app(config, state_store) -> QApplication` и `run(config=None) -> int`: грузит конфиг и
  состояние через `fly_pet.config`/`fly_pet.state`, ставит логирование через `fly_pet.logging_setup`,
  собирает кадры и окно, показывает его и запускает цикл событий. Ничего не печатает в stdout, кроме
  короткой строки «питомец запущен, данные: <каталог>» (по-русски).

## 4. `fly_pet/__main__.py`

- Добавить флаг `--gui` (запуск питомца через `app.run`). Без флага поведение прежнее:

## 5. Тесты (pytest, обязательно headless)

В тестах до импорта PyQt6 выставлять `os.environ.setdefault("QT_QPA_PLATFORM", "offscreen")`.

- `tests/test_animation.py`: все 13 кадров загружаются, размеры 64×64, группы по состояниям не пусты,
  `AnimationPlayer.advance()` циклится, `set_state` переключает набор, неизвестное состояние — ошибка.
- `tests/test_window_headless.py`: окно создаётся, размеры совпадают с конфигом, зум/анимация
  продвигается по таймеру вручную (`window._on_tick()` или публичный метод), перетаскивание меняет
  `pos()` и сохраняет состояние в `tmp_path`-каталог, `set_click_through(True/False)` не падает.
- Ни один тест не должен показывать окно на экране.

## Как проверить свою работу (обязательно выполни сам)
```
.venv/Scripts/python.exe -m pytest -q
QT_QPA_PLATFORM=offscreen .venv/Scripts/python.exe -m fly_pet --gui
```
Вторая команда должна запуститься без ошибок; чтобы она не висела, оберни её таймаутом (например,
запусти на 5 секунд и заверши) — в отчёте напиши, что именно увидел в выводе и убедился ли, что
процесс не упал. Перечисли созданные/изменённые файлы.
