# Задача 19: питомец живёт только на первом мониторе

## Что происходит
У владельца два монитора (на ПК; на ноутбуке один — проверять логикой и тестами). Сейчас:
- ходьба по столу ограничена `primaryScreen().availableGeometry()` — уже правильно;
- **окна-кандидаты для посадки не фильтруются по монитору**: `_pick_window_target` берёт любое окно,
  поэтому муха садится на окна второго монитора и уходит туда;
- «первый монитор» может быть **не** основным — тогда она ходит не там, где владелец считает «первым».

## Что сделать

1. **Конфиг** `window.monitor: 1` (по умолчанию `1`) — допускаются:
   - число `1`, `2`, … — номер монитора Windows (`QScreen.name()` вида `\\.\DISPLAY1` → номер 1);
   - `primary` — основной экран;
   - `all` — прежнее поведение (виртуальный экран, для отладки).
2. **Определение экрана при старте** (`fly_pet/app.py` или новый `screens.py`):
   - перебрать `QApplication.screens()`, взять тот, чей `name()` = `\\.\DISPLAY<n>` с нужным `n`;
   - если такого нет — WARNING и взять основной;
   - прямоугольник для ходьбы — `availableGeometry()` **этого** экрана;
   - INFO в лог: `мониторов: 2; экран: \\.\DISPLAY1 1920x1080 at (0,0) primary=True; область ходьбы:
     (0,0)-(1920,1032)`.
3. **Фильтр окон** (`filter_window_candidates` / `_pick_window_target`): окно годится, только если его
   полоса заголовка **лежит на выбранном экране** — центр полосы внутри прямоугольника экрана, и полоса
   пересекает его не меньше чем на 60% своей ширины. Окна, чей заголовок на другом мониторе, не
   предлагать никогда.
4. **Все прочие перемещения** — тоже внутри выбранного экрана: случайные перелёты стол→стол, паника от
   курсора, выбор точки перелёта. Проверить, что нигде не осталось `_virtual_screen_rect()` как области
   движения (он может остаться только для фильтра «окно вообще видно на экране» — и то лучше заменить).
5. **Демо-поедание**: если иконка тестового файла оказалась не на выбранном экране — WARNING в лог,
   реплика «файл не на моём экране», демо аккуратно завершается (файл убрать в карантин), оверлей не
   показывать.
6. **Fallback**: если выбранный экран пропал (монитор отключили/сменили раскладку) — в следующем тике
   пересчитать, взять основной, WARNING один раз. Питомец не должен зависнуть за пределами экрана.
7. Ничего не ломать: два режима локомоции, испуг курсором, Show Desktop/topmost, трей, мозг, сборку.

## Как проверять

```bash
cd D:/Projects/fly-pet
.venv/Scripts/python.exe -m pytest -q
# логика без реального второго монитора:
.venv/Scripts/python.exe -c "from fly_pet.screens import pick_screen_rect; print(pick_screen_rect(1))"
```
Юнит-тесты обязательны (без GUI): подставить фейковый список экранов
`[('\\\\.\\DISPLAY1', (0,0,1920,1080), True), ('\\\\.\\DISPLAY2', (1920,0,1920,1080), False)]` и проверить:
- при `monitor: 1` область = первый экран; при `2` — второй; при `primary` — primary; при `all` — объединение;
- окно с заголовком на `DISPLAY2` не попадает в кандидаты при `monitor: 1`;
- окно, чей заголовок частично залезает на первый экран, но центр на втором, — тоже не попадает.

## Отчёт

неуверенным (например, DPI на разных мониторах).
