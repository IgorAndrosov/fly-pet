## 1. `fly_pet/bubble.py` — облачко реплики

- `SpeechBubble(QWidget)`: frameless, `WA_TranslucentBackground`, `WA_ShowWithoutActivating`,
  **не** поверх всех окон, окно-инструмент (`Qt.Tool`) — как у питомца, чтобы не попадать в панель
  задач и не сворачиваться вместе со всеми.
- Рисуется в `paintEvent`: скруглённый прямоугольник (тёмный, полупрозрачный), светлый текст
  (шрифт приложения, размер из конфига), перенос слов, максимальная ширина из конфига; снизу-сбоку
  небольшой «хвостик» в сторону питомца.
- API: `say(text: str, ttl_ms: int | None = None)` — показать реплику, размеры подгоняются под текст;
  `attach_to(window: QWidget)` или метод позиционирования `place_near(anchor: QWidget)`: облачко
  ставится рядом с питомцем (по умолчанию сверху, если не влезает — снизу/слева), всегда оставаясь
  внутри `availableGeometry`; при перетаскивании питомца облачко, если оно видимо, следует за ним.
- Автоскрытие по таймеру (`ttl_sec` из конфига по умолчанию, либо переданное значение). Пустой текст
  — облачко не показывается.

## 2. `fly_pet/needs.py` — петля потребностей

- `Needs`: словарь hunger/energy/mood/attention (0–100), значения из `state`; методы `tick(dt_sec)` —
  убывание на `needs.decay_per_minute` × (dt/60) с клампом в 0–100, и `snapshot() -> dict[str, float]`.
- `NeedsEvents` (или возврат из `tick`): события при пересечении порогов из конфига —
  `hungry` (hunger выше `complain_hunger_above`), `sleepy` (energy ниже `sleep_energy_below`),
  `bored` (attention выше нового порога `needs.thresholds.bored_attention_above`, по умолчанию 80).
- Каждое событие срабатывает при **пересечении** порога (а не каждый тик) и не повторяется чаще, чем
  `needs.event_cooldown_sec` (новый ключ, по умолчанию 300).
- Режим питомца: если energy ниже порога сна — режим `sleep` (анимация `sleep`); когда energy
  поднимается выше порога + запас `needs.thresholds.wake_energy_above` (по умолчанию 35) — снова `idle`.
- Восстановление: пока питомец спит, energy растёт на `needs.restore_per_minute.energy`
  (новый ключ, по умолчанию 3.0), hunger при этом продолжает падать.
- фразы реплик — русские, по 2–3 варианта на событие, в `fly_pet/phrases.py` (отдельный модуль,
  простой dict): `hungry`, `sleepy`, `bored`, `woke`, а также `greeting` для запуска.

## 3. Сборка в `fly_pet/app.py` и `window.py`

- В приложении два независимых таймера: анимация (уже есть) и потребности с интервалом
  `tick.needs_interval_sec`; по тику: посчитать прошедшее время (`time.monotonic`), применить decay,
  обновить `state.needs`/`state.mode`, при событии — сказать реплику через `SpeechBubble` и переключить
  анимацию; сохранять состояние в `_data/state.json` не чаще раза в минуту и на выходе.
- `FlyWindow` получает метод `say(text)` (прокси к облачку) и метод `set_state(mode)`; облачко
  позиционируется относительно окна и следует за ним при перетаскивании.
- При запуске — одна приветственная реплика (из `phrases.greeting`), чтобы было видно, что питомец жив.
- Ничего не писать в stdout, кроме уже существующей строки запуска.

## 4. Конфиг `config/default.yaml`

Добавить с русскими комментариями: `bubble: {ttl_sec: 5, max_width: 260, offset_px: 14, font_pt: 10}`,
в `needs`: `event_cooldown_sec: 300`, `thresholds.bored_attention_above: 80`,
`thresholds.wake_energy_above: 35`, `restore_per_minute: {energy: 3.0}`.
Существующие ключи не менять. Пользовательские правки по-прежнему читаются из `_data/settings.yaml`
и побеждают.

## 5. Тесты (pytest, headless, `QT_QPA_PLATFORM=offscreen`)

- `tests/test_needs.py`: decay за 60 с равен `decay_per_minute`; кламп на нуле; событие `hungry`
  срабатывает один раз при пересечении порога и молчит внутри cooldown, снова срабатывает после него;
  `sleepy` переводит режим в `sleep`, восстановление energy выше `wake_energy_above` возвращает `idle`;
  пока спит — energy растёт, hunger падает.
- `tests/test_bubble.py`: `say` с текстом делает облачко видимым, размеры растут с длиной текста и не
  превышают `max_width`; пустой текст не показывает облачко; скрытие по таймеру (проверить вызовом
  обработчика, не ожиданием реального времени); позиция внутри `availableGeometry` для питомца у края
  экрана (проверить все четыре края).
- `tests/test_app_wiring.py`: сборка приложения поднимает оба таймера с интервалами из конфига;
  один «тик» потребностей приводит к изменению `state.needs` и сохранению состояния.
